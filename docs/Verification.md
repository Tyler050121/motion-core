# 按改动选择验证

下面是验证菜单，按受影响行为选择，不是每次任务的全量清单。
“存在实现”与“已验证运行”分开描述；历史验证不代表当前版本自动通过。

## 最小验证范围

| 改动 | 合适的证据 |
| --- | --- |
| 纯文档、技能说明 | 路径和链接、代码事实、指令是否冲突；无需启动 Unity |
| C# 行为 | Unity 导入/编译，以及受影响的最小 Editor 或 Play Mode 路径 |
| Prefab、场景、行为树等序列化资产 | Unity 加载/反序列化、受影响引用与运行行为 |
| 运行时生命周期 | 创建、禁用/释放、重新绑定或复用中受影响的路径 |
| 配置 Schema/源表 | 导出或校验、消费端加载，以及变更字段的效果 |

回归测试优先保护真实行为和已知易错边界。相关检查通过后，仅因新变化、失败或未解决风险扩大范围。
无法运行 Unity 时报告具体已做检查与待验证项；`rg`、YAML、`dotnet build` 均不证明运行时正确。
`MSB3644` 表示缺少引用程序集，不等于 Unity 代码编译失败。

## 运行入口

打开 `MotionCore/` 并确认工具连接到此项目。使用 `Launch.unity`，等待资源、配置、UI 就绪并进入
`SampleScene`。后者依赖 `CharacterSpawner` 等服务，不能单独替代启动验证。
退出后检查本次操作是否意外保存了场景或资产；用 Console 区分新增问题和已有问题。

## 专项路径

| 领域 | 关键观察点 |
| --- | --- |
| 启动 | 服务注册、YooAsset 就绪、UI 启动、场景加载；退出后服务释放、timeScale 恢复 |
| 输入与动画 | 受影响动作从输入到状态和动画；事件时机、退出窗口与旧动画事件过滤 |
| 命中 | 命中窗口 -> Hurtbox -> Health/Posture -> 反馈；窗口内去重、自身/同阵营过滤、同帧受击合并 |
| 闪避与卸势 | 事件窗口、实际重叠才产生完美闪避、一次反击资格；卸势独立结算，防御结束恢复倍率 |
| 破韧与处决 | 资格窗口、认领失败、距离/朝向/挂点；高额伤害不等于无条件死亡 |
| 死亡表现 | 世界条隐藏；延迟和溶解使用游戏时间；禁用后参数、Renderer 与碰撞恢复 |
| AI | 树可加载；索敌/交战；接受攻击才冷却；反应状态让位；超过节点半径后 Abort -> ClearTarget -> 回位 |
| 锁定 | Source 过滤、LockPoint 跟随、单轮切换耗尽取消、死亡/失活/超距清理 |
| UI/池 | Scope、开关竞态、注册/注销、重新绑定立即刷新；IgnoreDepth 仅作用于配置开启的 Widget |
| 资源 | 空目录和子目录查询、类型过滤、缓存复用与释放；EditorSimulate 不替代 Offline 包验证 |
| Audio | 播放/停止、跟随目标失效、循环音频释放、Mixer 路由与音量 |
| Save | 缺失与损坏数据区分、覆盖失败保留旧文件；用独立临时数据，目标平台/AOT 按需求验证 |

配置专项从 `3001/3002` 生成开始，检查受影响的位置、朝向、生命、架势或移动/转身数值及首次初始化时序。
导表入口在仓库同级 `../tools/`；只读检查在 `../tools/scripts/`。错误引用、数值范围和资源地址按变更选测，
临时测试数据结束后恢复。

Prefab 专项检查受影响组件、挂点、层、嵌套实例、变体移除组件和场景覆盖。
共享 `Characters` 父节点时特别关注自身过滤、处决、攻击前探、AI 自身定位和 VFX 方向；场景容器不代表角色。
死亡溶解需要现有 Renderer 材质支持 `_DissolveThreshold`，没有运行时材质模板替换路径。
